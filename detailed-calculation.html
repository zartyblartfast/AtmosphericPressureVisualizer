Understanding the Calculation Method

The visualizer estimates pressure from 0 to 100 km using a layered reference atmosphere. Altitude entered in the app is geometric height above sea level, z, in kilometres. Pressure is calculated in hPa and converted only for display. Defaults are P₀ = 1013.25 hPa and T₀ = 15 °C.

Layer-by-Layer Calculation

  1. Convert geometric to geopotential height below 86 km: H = R z / (R + z), with R = 6356.766 km. This accounts for decreasing gravity in the lower-atmosphere hydrostatic equations; H and z are not interchangeable.
  2. Start at sea level: T = T₀ + 273.15 kelvin and P = P₀. Traverse every intervening layer, carrying its top pressure and temperature into the next layer. The geopotential boundaries are 0, 11, 20, 32, 47, 51, 71, 84.852 km, with signed temperature gradients −6.5, 0, +1, +2.8, 0, −2.8, −2 K/km, respectively. Temperature differences in K/km and °C/km have the same numerical value.
  3. Integrate each layer: for base values Pb, Tb, gradient L and traversed geopotential height ΔH, T = T_b + L ΔH. If L ≠ 0, use P = P_b (T / T_b)^(−C/L). For an isothermal layer, P = P_b exp(−C ΔH / T_b). Here C = 34.1632 K/km. Using a single final temperature in a sea-level exponential is not equivalent to this integration.
  4. Join at exactly 86 geometric km: the rounded reference top H = 84.852 km corresponds almost, but not exactly, to z = 86 km. The last lower-layer gradient is continued to the exact join, H(86) ≈ 84.8520458 km.
  5. From 86 to 100 geometric km: use the reference log-pressure polynomial F(z) = 95.571899 − 4.011801 z + 0.06424731 z² − 0.0004789660 z³ + 0.000001340543 z⁴, normalized as P(z) = P(86) exp(F(z) − F(86)). This preserves the reference pressure-ratio shape while making pressure continuous at 86 km. It does not impose a zero temperature gradient above the join.

What the Temperature Control Assumes

Changing sea-level temperature offsets the whole lower temperature profile, keeping its gradients fixed, and reintegrates pressure through it. This is an educational pressure-response assumption, not a standard aviation ISA delta-T implementation: aviation-style temperature deviations commonly leave reference pressure fixed and change density instead. It is not a measured weather forecast. Above 86 km, the temperature offset changes only the boundary pressure P(86); the reference pressure ratio P(z)/P(86) is unchanged. No custom upper-atmosphere temperature model is calculated.

Verification and Limitations

The dependency-free Node tests compare default results against independent reference anchors: about 226.3226 hPa at 11 geopotential km and 54.7498 hPa at 20 geopotential km; 264.99893 hPa at 10 geometric km, 11.97031 hPa at 30 geometric km, and 0.004456799 hPa at 85 geometric km. Upper-atmosphere checks include about 0.0018359 hPa at 90 km and 0.000320124 hPa at 100 km. Lower checks allow rounding tolerances; upper checks allow 0.1% because the fitted reference shape, anchored to the integrated 86 km pressure, can differ slightly from published absolute values.

Tests also check exact sea-level pressure, linear sea-level-pressure scaling, continuity and decreasing pressure across layer boundaries and the 86 km join, positive pressures across 0–100 km at the UI temperature and pressure extremes, invalid inputs, and nonstandard-temperature behaviour. These are numerical model checks, not validation against local observations. The model does not account for humidity, changing weather, latitude, or variable upper-atmosphere composition and solar activity. The broad coloured atmosphere bands on the chart are schematic; dashed model-layer annotations use geometric positions and gradients per geopotential km.

The calculation accepts finite positive sea-level pressure, finite sea-level temperature, and geometric altitude from 0 through 100 km. Absolute temperature must remain positive throughout all traversed lower layers. Invalid inputs return NaN, without clamping to absolute zero or extrapolating outside the altitude range.
